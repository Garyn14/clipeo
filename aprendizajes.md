## ¿Qué es este archivo?
Patrones universales confirmados en MÁS DE UN
nicho. No se llena con suposiciones — solo con
evidencia real de múltiples nichos publicados.

## Estructura de aprendizajes por nicho
aprendizajes/
  zapatillas_peru.md  → nicho zapatillas peruanas
  sideral.md          → entidad sideral (nicho streamers_peru)

## Cómo registrar un aprendizaje
1. Publica el clip y espera 24-48h de datos
2. Anota en el archivo del nicho correspondiente
3. Si el patrón se confirma en otro nicho también
   → súbelo aquí como patrón universal
4. Actualiza el YAML del nicho si corresponde
